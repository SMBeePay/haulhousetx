# The Haul House

Static one-page site for haulhousetx.com (Royse City, TX).

- `index.html`: the whole site (HTML + CSS, no build step)
- `images/hero.jpg`: optional hero photo. If the file is missing, the hero shows text only.
- `assets/logo/`: logo files (SVG and PNG)

## Before going live

Replace the dashed placeholders in `index.html`: phone, email, payment methods, return policy, and the two Facebook links (`#fbLink`, `#fbLink2`).
